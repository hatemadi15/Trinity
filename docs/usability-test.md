# Three-person usability check

This is a test sheet to run with people; it is not a claim that user testing has already happened.

Recruit three people who have not used Earthrise. If possible include a technical participant, an educator and a beginner. Use the deployed build on at least one phone and one laptop. Give each person a fresh browser session and the same prepared case, without explaining the controls first. Ask them to think aloud; avoid pointing at the answer.

## Tasks

1. Compare two sites for the same arrival and lander. Which offers more continuous powered hours, and which offers more Earth visibility while powered?
2. Preserve the original plan, delay landing by seven days, and compare it with a nearby alternative on that delayed arrival. Explain what changed and whether the selected requirements are met.
3. Open the horizon view and explain one difference between the scenarios. Does “Earth in view” guarantee a working radio link? Does modeled power returning mean a vehicle survived the night?
4. Share the full comparison. Open the link in a fresh tab and check arrival, duration, battery, panel, mast and visibility margin. Find the printable comparison.
